# Yipeng Sun

I am an AI engineer at [NXAI](https://www.nx-ai.com) in Linz, Austria. I build embodied intelligence for robots.

## What I build

- **[diffct](https://github.com/sypsyp97/diffct)**: differentiable CT projectors for PyTorch. It supports arbitrary trajectories, multiple GPUs, multiple nodes, and geometry gradients. Install it with `pip install diffct`.
- **[Light-Whisper](https://github.com/sypsyp97/light-whisper)**: local and cloud speech-to-text for Windows. Hold a hotkey, speak, release. The text goes into your active app.

Smaller tools that I use every day:

- **[Kou](https://github.com/sypsyp97/kou)**: local dictation for macOS. Speech recognition runs on your Mac, and no audio leaves it.
- **[lidwake](https://github.com/sypsyp97/lidwake)**: keeps a MacBook awake with the lid closed while Claude Code work is active.

## What I maintain

- **[TiRex](https://github.com/NX-AI/tirex)** and **[TiRex-2](https://github.com/NX-AI/tirex-2)**: zero-shot time series forecasting models from NXAI.
