## 🛠️ What I build

- **[diffct](https://github.com/sypsyp97/diffct)**<br>
  A PyTorch library of differentiable CT projectors. You can use arbitrary trajectories, multiple GPUs, and multiple nodes. diffct also calculates the gradients of the geometry.
- **[Light-Whisper](https://github.com/sypsyp97/light-whisper)**<br>
  Speech-to-text for Windows with local and cloud engines. Hold a hotkey and speak. Release the hotkey, and the text goes into the active app.

### 🧰 Smaller tools that I use each day

- **[Kou](https://github.com/sypsyp97/kou)**<br>
  Local dictation for macOS. Speech recognition occurs on your Mac. Kou does not send audio out of your Mac.
- **[lidwake](https://github.com/sypsyp97/lidwake)**<br>
  lidwake prevents sleep on a MacBook with the lid closed while Claude Code is active.
